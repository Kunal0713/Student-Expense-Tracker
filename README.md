# Student Expense Tracker

A simple full-stack expense tracker built with React, Tailwind CSS, Express, MongoDB, and JWT authentication.

## Features
- Responsive home, about, contact, login, register, and dashboard pages
- Add, edit, delete, search, and filter expenses
- Authenticated dashboard with summary cards and recent transactions

## Run locally

### Server
```bash
cd server
npm install
npm run dev
```

### Client
```bash
cd client
npm install
npm run dev
```

The client will run at http://localhost:5173 and the server at http://localhost:5000.
